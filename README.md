# python
ต่อไปนี้คือประเภทข้อมูลที่ใช้บ่อยที่สุดใน Python:

จำนวนเต็ม: จำนวนเต็มที่ไม่มีทศนิยม เช่น10หรือ-5

my_integer_var = 10

print('Integer:', my_integer_var) # Integer: 10

Float: ตัวเลขที่มีจุดทศนิยม เช่น4.41หรือ-0.4.
my_float_var = 4.50

print('Float:', my_float_var) # Float: 4.5

สตริง: ลำดับของอักขระที่อยู่ภายในเครื่องหมายอัญประกาศเดี่ยวหรือคู่ เช่น'Hello world!'.

my_string_var = 'hello'

print('String:', my_string_var) # String: hello

บูลีน: ประเภทข้อมูลจริงหรือเท็จ เขียนแทนด้วยTrueหรือFalse

my_boolean_var = True

print('Boolean:', my_boolean_var) # Boolean: True

เซต: กลุ่มขององค์ประกอบที่ไม่ซ้ำกันซึ่งไม่มีลำดับ เช่น{0.5, 4, 'apple'}...

my_set_var = {7, 'hello', 8.5}

print('Set:', my_set_var) # Set: {7, 'hello', 8.5}

พจนานุกรม: ชุดของคู่คีย์-ค่าที่ล้อมรอบด้วยวงเล็บปีกกา เช่น <div class="key-value" {'name': 'John Doe', 'age': 28}>

my_dictionary_var = {'name': 'Alice', 'age': 25}

print('Dictionary:', my_dictionary_var) # Dictionary: {'name': 'Alice', 'age': 25}

ทูเพิล: ชุดข้อมูลเรียงลำดับที่ไม่สามารถเปลี่ยนแปลงได้ อยู่ภายในวงเล็บ เช่น('apple', 4.5, 7).

my_tuple_var = (7, 'hello', 8.5)

print('Tuple:', my_tuple_var) # Tuple: (7, 'hello', 8.5)

ช่วง (Range): ลำดับของตัวเลข มักใช้ในลูป เช่นrange(5).

my_range_var = range(5)

print('Range:', my_range_var) # Range: range(0, 5)

รายการ: ชุดขององค์ประกอบที่เรียงลำดับ ซึ่งรองรับประเภทข้อมูลที่แตกต่างกัน

my_list = [22, 'Hello world', 3.14, True]

print(my_list) # [22, 'Hello world', 3.14, True]

ไม่มี: ค่าพิเศษที่แสดงถึงการไม่มีค่าใดๆ

my_none_var = None

print('None:', my_none_var) # None: None
